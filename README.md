# Guia de uso rápido.

Debe ejecutarse desde el main, si no funciona, por favor reescribir los imports
en la sección gráfica.

Al entrar en la application se verán botones a la izquierda y
paneles con información a la derecha. En la esquina inferior
derecha se encuentra el monedero, donde se puede agregar
una cantidad infinita de dinero.

Una vez ingresado el dinero suficiente se puede hacer clic en
cualquiera de los botones de la izquierda, para comprar a traves
del comprador y una moneda virtual, que toma el mayor valor
posible en una sola moneda para efectuar la compra.

Cuando se dispense el producto aparecerá un botón en la sección 
"PUSH" de la máquina, al presionarlo este actualizará el panel del
Comprador, mostrando que se compró y cuanto vuelto recibió.
